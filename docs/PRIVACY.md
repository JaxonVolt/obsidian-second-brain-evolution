# 隐私与数据说明

## 本地保存的数据

插件会在用户自己的 Obsidian vault 中保存笔记、收件箱内容、会话历史、分流账本和插件设置。上述内容不属于本 GitHub 仓库，也不会被仓库自动收集。

## Codex

当用户主动发起对话、问库或收件箱分析时，相关提示词和上下文会交给本机 Codex CLI。数据如何传输和保留取决于用户使用的 Codex 账号、配置和 OpenAI 条款。普通快速捕获本身不调用模型。

## 微信远程入口

- 连接需要用户本人扫码确认。
- 连接凭据保存在插件本地数据中；Windows 上使用当前系统用户范围的加密保护。
- 收到的文字、图片和文件写入用户自己的 vault。
- 插件只处理已绑定会话的消息，不提供公开机器人入口。
- 转发卡片可能无法完整提取，插件会尽量保留可识别信息。

## 公开仓库不包含的内容

- 个人画像和真实笔记。
- 微信账号、令牌、二维码和加密后的凭据文件。
- Codex 会话、运行账本和本机路径。
- `.env`、`data.json`、vault 和调试日志。

提交 Issue 或 Pull Request 前，请再次检查截图、日志和测试夹具是否已经脱敏。
