# 5.7.0 公用版

## 本次内容

整合当前维护的日记与工作日志、收件箱确认分流、行动工作台、记忆管家、联合问库及微信收集功能。修复行动主记录与派生视图不同步、重复微信简报、并发捕获和文件变更后的检索缓存问题。

## 公用版默认设置

- LLM Wiki 关闭，程序与项目路径留空，由使用者填写；没有固定磁盘限制。
- 自动模型洞察和微信定时管家外发关闭，用户可手动开启。
- 初始化仅提供空白通用骨架，不包含作者背景、工作单位、真实日志或附件。
- 不附带 GitHub 凭据、私人同步任务或私有知识库。
- 生产构建不自动写入任何本地笔记库。

## 安装与升级

下载 ZIP，将 `second-brain-evolution` 文件夹放入库的 `.obsidian/plugins/`，再启用插件。也可手动安装三个单独文件。最低 Obsidian 版本为 1.11.5，仅桌面端。

升级前备份自己的库与插件设置，先在测试库运行。公用版的通用目录不会自动迁移旧库目录；日记优先遵循 Obsidian 每日笔记设置，工作日志默认放在 `100_领域与职责/140_工作日志`。

## 验证范围与限制

发布流程执行类型检查、静态检查、核心回归、优化回归、公用版边界回归、生产构建及公开内容扫描。合成测试覆盖空白初始化、不覆盖现有文件、写入冲突、行动状态、日志生成、简报去重与检索路径边界。

维护中的测试通过不代表继承的全部历史测试均已通过。`test:all` 仍含旧英文界面、旧路径与旧引擎的断言，后续逐步迁移；当前门禁使用 `npm test`。外部模型、微信服务、LLM Wiki 各版本以及所有操作系统的端到端兼容性不在本次自动测试承诺范围内。

此发布不包含扫描PDF识别能力，也不会自动提供PDF或Excel专用预览插件。

源码与安装包仅包含通用插件，不包含个人信息或私有仓库历史。第三方代码遵循现有 MIT 许可与 NOTICE 归属。
